# 童印代码结构与维护规范

童印为**一个 Go 服务 + 一个数据库 + 一个微信原生小程序**。后台页面已内嵌 Go，前端编译工具不是线上运行服务。

## 后端模块

| 模块 | 责任 |
|---|---|
| `backend/main.go` | 启动配置、依赖注入、路由注册，不写业务规则 |
| `backend/http_helpers.go` | JSON 响应、参数解析、用户与管理员身份校验 |
| `backend/media.go` | 图片、GLB 上传及签名文件链接 |
| `backend/work_handlers.go` | 原画上传、形象生成与作品确认 |
| `backend/checkout.go` | 下单、历史订单、收货地址快照 |
| `backend/pay.go` | 微信支付下单、回调验签与金额核对 |
| `backend/order_lifecycle.go` | 取消、退款申请等订单状态规则 |
| `backend/logistics.go` | 真实快递单、人工物流记录、快递100 |
| `backend/users_admin.go` | 运营用户管理、统计和审计 |
| `backend/accounts.go` | 小程序用户档案、后台账号与角色 |
| `backend/admin_search.go` | 后台数据库搜索与限额分页 |
| `backend/model.go` | 业务模型、Repository 接口及开发文件存储 |
| `backend/sqlstore.go` | PostgreSQL/MySQL 事务与持久化 |
| `backend/webadmin/index.html` | 管理后台唯一 HTML 页面 |
| `backend/webadmin/core.js` | 后台认证、API、筛选、分页及页面状态 |
| `backend/webadmin/views.js` | 作品、订单、用户等列表与详情渲染 |
| `backend/webadmin/actions.js` | 文件上传、物流发货、账号操作与事件处理 |
| `backend/webadmin/app.css` | 运营后台通用样式 |
| `backend/admin_embed.go` | 静态后台资源嵌入 Go 程序 |

## 小程序模块

- `miniprogram/utils/api.js`：所有 HTTP 请求、令牌自动续期。
- `miniprogram/utils/identity.js`：从 `/api/me` 获取已验证的登录状态。
- `miniprogram/utils/shipping.js`：收货地址校验与微信地址选择；订单详情和预览页共用。
- `miniprogram/utils/order.js`：订单状态文案、价格和日期统一格式。
- 页面只负责 UI 状态与事件；复用逻辑不在多个页面复制粘贴。

## 代码规范

1. **Go 一律使用 `gofmt`**，JS/CSS/HTML 使用仓库根目录的 Prettier 配置。不要手动用空格排 Go。
2. 复杂的业务规则、身份隔离、支付竞态、订单状态流转，用中文注释解释**为什么**，不逐行翻译代码。
3. 服务端处理的用户身份来自已验证的登录令牌，不能信任客户端提供的 `owner`。
4. 地址是用户常用数据；订单是独立收货快照，二者不能因为编辑而被意外同步。
5. 微信支付与退款只依据真实商户接口结果；物流轨迹只接受真实平台或人工核实数据。
6. 查询列表默认分页与限额，不允许管理界面重新恢复“前端获取全量后过滤”的模式。
7. 管理后台代码只有 `backend/webadmin` 一套，Go 直接嵌入；修改代码无需第二个进程。
8. 新增模块应同时更新相关测试，不能靠禁用测试获得 CI 通过。

## 验证命令

```powershell
cd backend
gofmt -w *.go
go test ./...
cd ..
node scripts/check-miniapp-3d.cjs
node scripts/check-miniapp-identity.cjs
node scripts/check-order-flow.cjs
node scripts/check-operations.cjs
node scripts/check-admin-search.cjs
```

如果已安装 Prettier，可以在项目根目录运行（只需开发环境）：

```powershell
npx prettier --write 'backend/webadmin/**/*.{html,css,js}' 'miniprogram/pages/**/*.js' 'miniprogram/utils/*.js'
```

不要用 Prettier 的 HTML 解析器批量重排微信 WXML；WXML 属性和模板语法应按微信开发者工具的结果独立验证。
