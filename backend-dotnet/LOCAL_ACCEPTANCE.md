# 童印 .NET 10 本地迁移验收清单

本清单用于使用现有仓库 `feat/dotnet-backend-migration` 分支进行 **C# 后端验收**。测试前保持 Go 代码和现有数据库不变。

## 1. 安全启动

- [ ] 安装 .NET SDK 10，执行 `dotnet --version`，显示 `10.x`
- [ ] 在当前仓库切到 `feat/dotnet-backend-migration`
- [ ] 从 `backend-dotnet` 目录运行 `verify-local.ps1`（或 README 中相同命令），保存 **全部输出**
- [ ] 执行 `run-local.cmd`，看到监听 `http://localhost:18080`
- [ ] 记录首次启动终端显示的随机管理员密码（不要提交到 GitHub）
- [ ] 用浏览器打开 `http://localhost:18080/admin/`，检查登录与首页、AI 模型配置页面
- [ ] 检查 `http://localhost:18080/admin/3d/` 可加载 3D 预览页面的静态 JS 资源（预览需要模型时以页面提示为准）
- [ ] 浏览器开发者工具检查 /admin/ 下 JS、CSS、.mjs 无 404 和模块 MIME 错误

> `run-local.cmd` **只使用** `backend-dotnet/data/` 下的独立 file 数据存储，避免污染 Go 的 PostgreSQL 或 media 目录。当前分支 `miniprogram/config.js` 仍使用原来的 18080，**启动 C# 前必须先停止 Go 以释放端口**。发布前须使用合法 HTTPS 域名。

## 2. 微信小程序业务流程（开发者工具）

- [ ] 小程序开发工具关闭本地调试的合法域名校验，确认仅本地 DEV_LOGIN 环境测试
- [ ] 上传 1 张儿童画，作品在「进行中」和后台作品列表中均可找到
- [ ] 在后台对该作品手动上传 1 张卡通形象图，回到小程序确认可看到同一张图
- [ ] 用户选中该图后，状态进入 `model_pending`
- [ ] 后台上传一份 **有效的 GLB 模型**，小程序打开模型预览，可旋转、全屏
- [ ] 测试地址保存、编辑待支付订单的地址、订单创建
- [ ] 同一作品重复创建订单必须拒绝
- [ ] 取消未发起支付的订单后，后台订单状态为 `canceled`
- [ ] 未配置微信正式支付参数时，点击付款应友好失败，不会伪造成功记录

## 3. 后台权限与数据

- [ ] 管理员可以添加运营、生产、发货和客服账号
- [ ] 运营、客服无法访问 owner 专属 AI Key、审计及账号管理
- [ ] 非 owner 无法停用客户账号
- [ ] 管理员作品/订单搜索支持状态、分页，非法 `page`、`page_size` 返回 400
- [ ] 上传的 GLB 和图片不能跨作品非法复用，客户端只能查询自己的作品/订单
- [ ] 现有图片、模型和订单历史正常显示，返回体不包含客户 OpenID、API Key 明文

## 4. AI、支付、物流外部联调（有凭据后再测试）

- [ ] 在隔离环境用 Seedream **测试 Key** 验证 1 次儿童画生图
- [ ] 有效卡通图 → 3D Worker → GLB 回调成功；重复或过期回调被拒绝
- [ ] 请求中断时可以用 trace 对应日志排查，没有打印 API Key 或儿童画 Base64
- [ ] 用微信支付测试商户进行预支付、签名/验签、取消与重复回调验收；**不可使用真实用户产生不可控扣款**
- [ ] 微信已支付的订单才能生产、发货；重复支付通知不能重复记账
- [ ] 录入快递单号、手工真实轨迹和快递100 API；30 分钟内刷新限制生效
- [ ] 退款请求仅记录申请，须由商户实际执行并核对到账，不会假报成功

## 5. 旧数据兼容（必须使用副本）

- [ ] 备份原 Go PostgreSQL/MySQL 数据库和 `DATA_DIR/media`
- [ ] 将备份克隆成 **另一个数据库**；配置 C# 指向克隆库和媒体副本，确保保留原 `SESSION_SECRET`
- [ ] 旧管理员账号可登录、旧登录 token 有效、原 AI API Key 可解密
- [ ] 旧作品状态、旧 GLB、用户档案、地址、订单、运单和审计记录保留
- [ ] 反复启动不会重复迁移用户，也不会修改不该修改的订单状态
- [ ] C# 写入克隆库后，至少验证旧格式的作品、用户、订单均可继续读取

## 6. 删除 Go 的条件

**以上实际验收与最新 C# CI 全部通过后，明确确认再删除 Go。** 删除会单独提交，不通过本分支暗中删除。

本地测试遇到问题时，请提供：`dotnet --version`、失败命令、异常完整堆栈（脱敏）及小程序报错页面。不要提供密码、API Key、儿童原画 Base64、真实收货信息、商户私钥或生产库连接串。
